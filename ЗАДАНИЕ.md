# Задание

Отрефакторить вьюмодели так, чтобы они не работали напрямую с окнами, файлами и данными.

1. Сделайте `IDialogService` для диалогов и сообщений.
2. Сделайте `IFileService` для сохранения и загрузки.
3. Сделайте `IDataService` для хранения компаний и людей.
4. Сделайте `IApplicationLifeTimeService` для завершения приложения.
5. Передайте сервисы во вьюмодели через конструктор.
